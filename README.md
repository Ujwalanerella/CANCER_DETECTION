# CANCER_DETECTION
This project uses machine learning techniques to detect cancer based on clinical and diagnostic data. It aims to assist healthcare professionals by providing an AI-powered tool that predicts whether a patient may have cancer based on routine medical tests.

## Project Overview

- **Type**: Classification (Binary)
- **Input**: Structured medical data (e.g., tumor features, blood test results)
- **Output**: Cancer Prediction (Benign or Malignant)
- **Tech stack**: Python, Scikit-learn, Pandas, NumPy, Streamlit

## Dataset

I used a publicly available dataset.
Each record contains features like:
- Radius
- Texture
- Perimeter
- Area
- Smoothness

## Features

- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Selection
- Model Training (Logistic Regression, Random Forest, SVM, etc.)
- Performance Evaluation (Accuracy, Precision, Recall, F1-score, ROC-AUC)
- Streamlit Web App for predictions
